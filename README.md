Persona 5 Fan Website

A fan-made website dedicated to the Persona 5 universe, created as a web development project using HTML, CSS, and JavaScript.

--About the Project--

This website provides information about Persona 5, including its characters, games, and other media.
The project was created to practice and demonstrate front-end web development concepts such as:

HTML structure

CSS styling and layouts

JavaScript interactions

Custom fonts

Image handling

Interactive character and game sections

Responsive and user-friendly design

--Technologies--

HTML

CSS

JavaScript

--Design--

The website's visual design is inspired by the distinctive red, black, and white aesthetic of Persona 5.
